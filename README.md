# SPOD sound

This project quantifies the generated sound of the near-field reconstructed using a specified number of SPOD modes. This is carried out using LES data 
for a subsonic (Mach 0.67) round jet and a subsonic 16-chevron serrated jet with Reynolds number of order 10^6. The aim of the project is to determine if the relevant changes to the 
far-field intensity spectrum can be captured using a few near-field SPOD modes. 

A formula has been developed to calculate the sound generated by each azimuthal mode of the lighthill tensor. The details of the derivation of this formula is given in the document 
'bessel_lighthill_derivation.docx'.
